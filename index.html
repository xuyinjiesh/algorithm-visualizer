GET STARTED

从源码到结构，只需三步

  1. 在左侧编辑 C++，也可以打开本地 .cpp 文件。
  2. 点击“添加变量”，填写变量名、结构类型、尺寸或字段，以及采集行。
  3. 点击“编译并运行”，在右侧同时观察全部结构，用时间轴回放。

无需手写 viz::watch 或 VIZ_STEP。工具只在编译副本中插入采集代码，下载的源码保留原样。采集行必须位于变量有效的作用域中；未执行到该行的变量会显示“尚未采集”。

不同采集行的变量保留最近一次采集结果，并标明采集步骤。修改代码或观察配置后，重新运行即可更新视图。

LeetCode 代码可选择“LeetCode · class Solution”模式，填写 public 方法名和 JSON 参数。工具补全常用标准库、std 命名空间和 main()，按方法签名转换参数并输出返回值；void 方法会输出调用后的参数。需要 ListNode / TreeNode 时可选择补全节点定义。观察变量和行号仍以左侧原始代码为准。

快捷键：Ctrl + Enter 编译并运行；F5 下一步，Shift + F5 上一步，在源码编辑器内也有效，并会暂停自动播放。回退直接恢复上一帧采集的数据，无需重新编译。没有轨迹时会提示先运行，第一步和最后一步不会越界。Ctrl + F5 保留浏览器刷新功能。
